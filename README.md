# 📘 IA Aplicada à Melhoria Contínua com NotebookLM

## Sobre o projeto

Este projeto foi desenvolvido durante o curso da DIO com o objetivo de explorar o uso do NotebookLM como ferramenta de aprendizagem ativa.

O tema escolhido foi **Inteligência Artificial aplicada à Melhoria Contínua**, buscando compreender como a IA pode apoiar profissionais na análise de processos, organização do conhecimento e tomada de decisão.

---

## Objetivos

- Aprender a utilizar o NotebookLM.
- Desenvolver habilidades em Engenharia de Prompts.
- Organizar conhecimento de forma estruturada.
- Criar um material reutilizável para estudos futuros.
- Publicar um projeto profissional no GitHub.
